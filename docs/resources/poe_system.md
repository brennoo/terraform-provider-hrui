# hrui_poe_system (Resource)

Manages global Power over Ethernet (PoE) system power budget settings and reports total PoE consumption telemetry.

## Introduction

This resource manages the global Power over Ethernet (PoE) system power budget on PoE-capable HRUI switches. You can configure the total PoE power limit in Watts using `power_limit_watts`, and inspect live system-wide PSE telemetry through the computed `power_consumption_watts` and `power_usage_percent` attributes.

## Example Usage

```terraform
resource "hrui_poe_system" "example" {
  power_limit_watts = 100
}
```

## Schema

### Required

- `power_limit_watts` (Number) Total PoE power budget in Watts configured on the switch.

### Read-Only

- `power_consumption_watts` (Number) Current total PoE power consumption in Watts reported by the PSE controller.
- `power_usage_percent` (Number) Current total PoE power usage percentage reported by the switch.
