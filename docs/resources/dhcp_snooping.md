# hrui_dhcp_snooping (Resource)

Manages global DHCP Snooping state and per-port trusted DHCP server ports.

## Introduction

This resource manages global DHCP Snooping and per-port DHCP trust settings on the switch. DHCP Snooping protects the network against rogue DHCP servers by filtering untrusted DHCP server messages (such as `DHCPOFFER` and `DHCPACK`). Use `enabled` to toggle DHCP Snooping globally and `trusted_ports` to specify which uplink or server-facing ports are allowed to forward DHCP server responses.

## Example Usage

```terraform
resource "hrui_dhcp_snooping" "example" {
  enabled       = true
  trusted_ports = ["Port 1"]
}
```

### Required

- `enabled` (Boolean) Whether global DHCP Snooping is enabled on the switch.

### Optional

- `trusted_ports` (List of String) List of switch ports configured as trusted DHCP server ports (e.g., ['Port 1', 'Port 5']). Untrusted ports only allow DHCP client traffic.
