# hrui_poe_port (Resource)

Manages Power over Ethernet (PoE) administrative configuration on a switch port and exposes live PSE telemetry.

## Introduction

This resource manages Power over Ethernet (PoE) administrative settings on an individual switch port. You can enable or disable PoE power delivery with `enabled`, select the IEEE 802.3 PSE protocol profile (`BT`, `HiPoE`, `AT`, or `AF`) via `pse_type`, and toggle the PoE watchdog (`PoEDog`) via `watchdog_enabled`. The resource also exposes live per-port PSE telemetry including `operation`, `pd_class`, `power_watts`, `voltage_volts`, and `current_ma`.

## Example Usage

```terraform
resource "hrui_poe_port" "example" {
  port             = "Port 1"
  enabled          = true
  pse_type         = "AT"
  watchdog_enabled = false
}
```

## Schema

### Required

- `enabled` (Boolean) Whether PoE power delivery is administratively enabled on the port.
- `port` (String) The PoE port name (e.g., 'Port 1').

### Optional

- `pse_type` (String) PoE protocol type configured on the port ('BT', 'HiPoE', 'AT', or 'AF').
- `watchdog_enabled` (Boolean) Whether the PoE watchdog (PoEDog) is enabled on the port.

### Read-Only

- `current_ma` (Number) Live PoE current draw on the port in milliamps (mA).
- `operation` (String) Current PoE operational state ('On' or 'Off').
- `pd_class` (String) Detected Powered Device (PD) IEEE 802.3 class (e.g., 'AT(Class4)', 'AF(Class3)', or '-').
- `power_watts` (Number) Live PoE power draw on the port in Watts.
- `voltage_volts` (Number) Live PoE bus voltage on the port in Volts.
